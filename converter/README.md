A quick and dirty video converter for Mecha-telly
-------------------------------------------------

It will crop a tiny bit, scale to 32x32 and mux with audio into frames that can be used with Mecha-telly.

## Usage

To convert hypnotoad.mp4 to hypnotoad.pcm and hypnotoad.pcz:

```
./convert-pcm.sh hypnotoad.mp4 hypnotoad.pcm
```
